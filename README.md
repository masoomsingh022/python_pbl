## Phase 3: Model Training and Evaluation

In this phase, multiple Machine Learning classification models were trained using the preprocessed air quality dataset to predict AQI categories. The dataset was divided into training and testing sets using the train-test split method. Feature scaling was performed using `StandardScaler` to improve model performance.

### Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

### Steps Performed
- Split dataset into training and testing sets
- Applied feature scaling using `StandardScaler`
- Trained all classification models
- Generated predictions on test data
- Compared model performances

### Evaluation Metrics
- Accuracy Score
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report
- ROC Curve

The performance of all models was analyzed and compared to identify the best-performing classifier for air quality prediction.
