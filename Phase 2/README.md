## Phase 2: Exploratory Data Analysis and Feature Engineering

In this phase, exploratory data analysis (EDA) and feature engineering techniques were performed to better understand the dataset and improve model performance.

### Exploratory Data Analysis
- Generated correlation heatmaps to analyze relationships between features
- Visualized AQI category distribution using count plots
- Identified important pollutant and weather-related features

### Feature Engineering
- Extracted date-time features such as:
  - Year
  - Month
  - Day
  - Day of Week
- Applied one-hot encoding for city names
- Applied label encoding for AQI categories
- Prepared the final cleaned dataset for model training

### Tools and Libraries Used
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
